# 도쿄 맛집 — 어디든 올릴 수 있는 웹앱

유튜브 「토요일의 도쿄」 영상 설명란에서 모은 도쿄 맛집을 폰에서 보는 앱.
정적 호스팅에 그대로 올리면 일반 웹사이트 주소로 열린다 → https://kimdg0116.github.io/tokyo-food/

```
index.html              앱 본체 (CSS·JS 전부 포함, 빌드 도구 없음)
data.json               가게 목록 — 옵시디언 노트에서 자동 생성
thumbs/                 가게 사진 (유튜브 영상 썸네일)
manifest.webmanifest    홈 화면 앱 설정
sw.js                   오프라인 캐시 (서비스 워커)
version.json            현재 버전 — 앱이 이 파일로 새 버전을 알아챈다
.nojekyll               GitHub Pages 가 `_` 로 시작하는 파일을 숨기지 않게 (필수)
apple-touch-icon.png    아이폰 홈 화면 아이콘 (180×180)
icon-192.png / icon-512.png
```

## 기능

- **요일 줄** (상단 고정) — 일~토. 고른 요일 기준으로 카드에 **그날 영업시간**(초록) · **휴무**(빨강, 카드 흐려짐) · **부정기**(노랑) · **시간 미상**(회색) 배지가 뜬다. 오늘은 테두리로 표시
- **그날 여는 곳만** 토글 — 그 요일에 쉬는 곳을 목록에서 숨긴다 (부정기·시간 미상은 남긴다)
- 고른 요일이 **오늘**이면 지금 상태도 함께 — `영업 중 · 23:00까지` / `마감 40분 전` / `17:00 오픈` (도쿄 시간 기준, 새벽 영업도 계산)
- 탭: 전체 · 추천 · ★ 찜 · ✓ 가봄
  - 추천 **인기순** — 가게가 나온 영상 조회수 상위 30곳 (체인 제외)
  - 추천 **숙소 가까운 곳** — `🗺 도쿄 맛집` MOC 의 후보 표 (숙소 20분 이내 + 조회수 상위)
- **필터** 시트 — 지역 · 종류는 세로 목록(다중 선택), 가격대는 칩
- **목록 / 지도** 전환 (OpenStreetMap) · **내 주변**(거리순, 위치는 저장 안 함)
- 가게마다 **구글맵**(앱으로 열림) · **영상**(유튜브로 열림) · ★찜 · ✓가봄
- 상세: 요일별 영업시간 표, 전체 메뉴, 주소 **복사** 버튼(택시 기사에게 보여주기용), 평점

## 아이폰에 설치

사파리로 주소를 열고 → 공유 → **홈 화면에 추가**.
처음 열 때 사진까지 받아두므로 **지하철·데이터 없는 곳에서도 목록과 사진이 보인다.** 지도 타일과 구글맵·영상은 인터넷이 필요하다.

## 알아둘 것

- 찜·가봄은 **브라우저(기기)별로 따로** 저장된다. 링크를 공유해도 서로 섞이지 않는다.
- 가게 id 는 **이름에서 만든다**(`s` + 해시). 중간에 가게를 끼워 넣어도 찜·가봄이 밀리지 않는다. 예전 순서기반 id 는 `tokyo_food_idmap.json` 으로 한 번 옮긴다.
- 체인점·한정판·이벤트에는 영업시간 배지를 달지 않는다 (개념이 다름).
- 영업시간은 구글 지도와 웹에서 모은 값이라 **바뀌었을 수 있다.** 멀리 가기 전엔 구글맵으로 한 번 더 확인.

## 업데이트 (노트를 고친 뒤)

볼트 폴더에서:

```
python3 "90 System/scripts/tokyo_food_geocode.py"       # 새 가게 좌표 (있는 곳은 건너뜀)
python3 "90 System/scripts/tokyo_food_hours_google.py"  # 영업시간·휴무·평점 (구글 Places, 가게당 1회 호출)
python3 "90 System/scripts/tokyo_food_apply_hours.py"   # 위 결과를 노트에 반영
python3 "90 System/scripts/tokyo_food_views.py"         # 유튜브 조회수 갱신 (선택)
python3 "90 System/scripts/build_tokyo_food_app.py"     # data.json + thumbs 생성, 버전 스탬프
```

그 다음 `~/Documents/tokyo-food` 에서 `git add -A && git commit -m "…" && git push`.
앱을 열면 `version.json` 을 보고 **「새 버전이 있어요」** 알림을 띄운다.

> 구글 Places 키는 `~/.config/tokyo-food/google_places.key` (권한 600).
> 다 쓴 뒤에는 Cloud Console 에서 **할당량을 0 으로 낮추거나 키를 삭제**해 두면 과금될 길이 없다.

# 다른 도시에도 쓰려면

이 앱은 도쿄 전용이 아니다. **옵시디언의 지역 노트 폴더 하나**가 전부다.
`04 Life/여행/<도시 YYYY-MM>/맛집/` 아래 지역별 `.md` 를 만들면 그대로 앱이 된다.

## 1. 노트 형식 (빌더가 읽는 규칙)

지역 노트 하나 = 앱의 지역 하나. **파일 이름이 곧 지역 이름**이다.

````markdown
---
title: 오사카 맛집 · 난바
category: life
type: note
topics: ["[[🗺 오사카 여행 2027-03]]"]
---

# 난바

> [!info] 12곳 · 「○○」 채널 정리        ← 곳수 (사람이 보는 용도)

## 한눈에 보기

| 가게 | 종류 | 대표 메뉴 | 가격대 |
|---|---|---|---|
| **가게이름** | 라멘·면 | 대표메뉴 | ~1,500엔 |

---

## 라멘·면                        ← `## 장르` = 그 아래 가게들의 종류

### 가게이름　`日本語店名`          ← `### 이름`, 전각 공백 뒤 일본어 상호(선택)
![[영상ID.jpg|320]]              ← `_썸네일/` 폴더의 사진

*라멘·면 · ~1,500엔 · `日本語店名`*    ← 종류 · 가격대 · 일본어 (순서 자유)
**대표 메뉴** — 메뉴A · 메뉴B

- 📍 주소 (여러 줄 가능)
- 🕒 영업시간 · 휴무 … (출처 · 확인일)
- 🔗 [구글맵](단축링크) · [영상](유튜브링크) · [공식](사이트)
- 🍽 메뉴
	- 메뉴 이름 1,000엔
- ℹ️ 가격이 있는 부가 메뉴
- 🔎 메모 (배경·팁)
- ⚠️ 주의 (확인 못 한 것, 폐업 의심 등)
- 💰 가격·판매 기간 (한정 상품용)
- 📅 기간 (이벤트용)
````

- 가격대는 `~1,500엔` · `1,500~3,000엔` · `3,000~6,000엔` · `6,000~12,000엔` · `12,000엔+` 다섯 단계.
  단품 가격(`990엔`)을 써도 앱이 알아서 구간에 넣는다
- 사진은 `맛집/_썸네일/<파일>.jpg` 에 두면 빌더가 480px 로 줄여 `thumbs/` 로 복사한다
- 영업시간 줄(`🕒`)은 두 형식을 다 알아듣는다 — `월 11:30~14:00 · 화 …` 와 `월~금 런치 … / 토 …`

## 2. 빌더 설정 네 군데만 고친다

`90 System/scripts/build_tokyo_food_app.py` 맨 위:

```python
FOOD = VAULT / "04 Life/여행/<도시 YYYY-MM>/맛집"      # 노트 폴더
OUT  = pathlib.Path.home() / "Documents" / "<앱폴더>"   # 앱을 만들 곳
REGIONS = ["난바", "우메다", ...]                       # 지역 노트 이름 (보이는 순서)
TAIL_REGIONS = ["기타 지역", "체인점", ...]              # 맨 뒤로 보낼 노트
```

`GENRE_FOLD` 는 잘게 쪼개진 종류를 큰 분류로 묶는 표다. 도시가 바뀌어도 그대로 쓸 수 있다.

## 3. 나머지 스크립트는 그대로 돌아간다

좌표(`tokyo_food_geocode.py`) · 영업시간(`tokyo_food_hours_google.py`) · 조회수(`tokyo_food_views.py`) 는
모두 `data.json` 을 읽어 동작하므로 **도시와 무관하다.** 캐시 파일 이름만 도시별로 바꾸면 섞이지 않는다.

- 좌표 판정 범위는 `tokyo_food_geocode.py` 의 `BOUNDS`(위도·경도 사각형)를 그 도시에 맞게 고칠 것
- 지역 재분류(`tokyo_food_move_region.py`)의 구·동 → 지역 매핑은 도시마다 새로 써야 한다.
  일본 밖이면 이 단계는 건너뛰고 좌표만 써도 된다 (GSI 역지오코딩은 일본 전용)

## 4. 앱 자체는 손댈 곳이 거의 없다

`index.html` 에서 도시에 묶인 것은 **이름·아이콘·출처·초기 좌표·시간대**뿐이다.

- `<title>` · `.brand` 문구 · `manifest.webmanifest` 의 이름
- 푸터의 출처 줄 (유튜브 채널 링크)
- 지도 초기 위치 — `L.map("map").setView([35.69, 139.72], 12)`
- 시간대 — 영업 상태 계산에 **+9시(JST)** 를 쓴다. 다른 시간대면 `tokyoNow()` 의 `540`(분)을 고칠 것

## 5. 새 저장소로 배포

GitHub 에 새 저장소를 만들고 `git remote add origin …` 후 push.
`Settings → Pages → Deploy from a branch → main / (root)`.
**`.nojekyll` 을 꼭 같이 올릴 것** (없으면 `_` 로 시작하는 파일이 404 가 된다).
