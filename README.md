# 도쿄 맛집 — 어디든 올릴 수 있는 버전

유튜브 「토요일의 도쿄」 영상 설명란에서 모은 도쿄 맛집 216곳. 정적 호스팅에 그대로 올리면 일반 웹사이트 주소로 열립니다.

```
index.html              앱 본체 (CSS·JS 전부 포함)
data.json               가게 목록 — 옵시디언 노트에서 자동 생성
thumbs/                 가게 사진 (영상 썸네일, 178장)
manifest.webmanifest    홈 화면 앱 설정
sw.js                   오프라인 캐시 (서비스 워커)
version.json            현재 버전 — 앱이 이 파일로 새 버전을 알아챈다
apple-touch-icon.png    아이폰 홈 화면 아이콘 (180×180)
icon-192.png            안드로이드·데스크톱 아이콘
icon-512.png            스플래시 화면 아이콘
```

## GitHub Pages 에 올리기

1. github.com 에서 새 저장소 만들기 (Public) — 예: `tokyo-food`
2. 이 폴더의 파일을 전부 업로드 (`Add file → Upload files`). **`thumbs` 폴더는 폴더째 끌어다 놓기**
3. `Settings → Pages → Source: Deploy from a branch → main / (root)` 저장
4. 1~2분 뒤 https://kimdg0116.github.io/tokyo-food/ 로 열립니다

## 아이폰에 설치

사파리로 위 주소를 열고 → 공유 → **홈 화면에 추가**.
처음 한 번 열 때 사진까지 전부 받아두므로, **지하철·데이터 없는 곳에서도 목록과 사진이 보입니다.**
구글맵·영상 버튼은 인터넷이 있어야 열립니다.

## 기능

- 탭: 전체 · 추천 · ★ 찜 · ✓ 가봄
  - 추천 **인기순** — 가게가 나온 유튜브 영상 조회수 상위 30곳 (체인점 제외, 한 영상에 여러 곳이면 같은 조회수)
  - 추천 **숙소 가까운 곳** — 숙소(이케부쿠로)에서 전철 20분 이내 + 조회수 상위 23곳 (`🗺 도쿄 맛집` MOC 후보 표)
- **필터** 버튼 → 아래에서 올라오는 시트. 지역 · 종류는 세로 목록, 가격대는 칩. 여러 개를 함께 고를 수 있다
- **목록 / 지도** 전환 — 지도는 OpenStreetMap. 추천 탭에서는 핀에 순위 번호
- **내 주변** — 현재 위치에서 가까운 순으로 정렬하고 거리 표시 (위치는 저장하지 않음)
- 가게마다 **구글맵**(구글맵 앱으로 열림) · **영상**(유튜브 앱으로 열림) 버튼
- 상세 화면: 전체 메뉴, 영업시간, 주소 **복사** 버튼 (택시 기사에게 보여주기용)

## 주의

- 좌표는 194곳. 체인점과 위치 미상 등 22곳은 지도에 안 나오고 목록에만 있습니다.
- 지도 타일은 오프라인 저장을 하지 않습니다. 지도는 인터넷이 있을 때만 보입니다.
- 찜·가봄은 **브라우저별로 따로** 저장됩니다. 링크를 공유해도 서로 섞이지 않습니다.
- 영업시간·휴무일은 원본에 거의 없습니다. 가기 전 구글맵으로 확인하세요.

## 업데이트

옵시디언 노트(`04 Life/여행/도쿄 2026-09/맛집/`)를 고친 뒤, 볼트 폴더에서:

```
python3 "90 System/scripts/tokyo_food_geocode.py"   # 새 가게 좌표 (이미 있는 곳은 건너뜀)
python3 "90 System/scripts/tokyo_food_views.py"     # 조회수 새로 읽기 (선택)
python3 "90 System/scripts/build_tokyo_food_app.py"
```

`data.json`, `version.json`, `sw.js`, `index.html` 네 파일(+ 새 사진이 있으면 `thumbs/`)을 함께 올립니다.
앱을 열면 `version.json` 을 보고 「새 버전이 있어요」 알림을 띄웁니다.
